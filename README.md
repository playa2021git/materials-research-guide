# 材料の組み合わせ探究

中学1年生向けの生徒用マニュアル。説明10分＋個人作業30分で、Googleスライド全4ページを作ります。①②が全員必須、③④は挑戦。成果物は成績評価の対象です。

## 教材

- ① 製品写真と部品の材料：材料が正しく対応しているか。
- ② 材料を選ぶ理由：具体的な材料特性と部品の役割を結び付け、自分の言葉で詳しく考察。
- ③ 材料変更提案と画像・インフォグラフィック：①②と別製品でも可。
- ④ AIの指摘に納得した点・疑問や異論、その理由と修正案を自分の言葉で考察。画像生成は不要。

教室のスライドドアを題材とした仮の見本、写真の権利・出典、AIの誤りへの注意、提出前チェックを掲載。画像生成の「1日4回以内」は授業の目安で、サービスの利用上限の保証ではありません。明らかな誤りの無批判なコピーは減点となる旨を明記しています。

## 使い方

`index.html` をブラウザで開くだけで利用できます。外部ライブラリ、ビルド、通信、ログインは不要です。スマートフォン表示と印刷に対応。チェック項目はそのページ内だけで動作し、保存・送信しません。

公開先： https://playa2021git.github.io/materials-research-guide/

GitHub Pagesの公開設定は `main` ブランチのルート `/` を使用します。未設定の場合はリポジトリの **Settings → Pages → Deploy from a branch → main / (root) → Save** で有効化できます。

## 先生が授業前に案内するもの

- Googleスライドの作成・配付方法と提出先、提出方法。
- 「素材の組み合わせ探求サポーターGem」の実際のリンクと利用可能な機能。リンクは未提供のため、このページでは架空のリンクを設置していません。
- 見本が仮の設定であること。実物の材質は製品表示・メーカー資料等で確認すること。

このリポジトリはマニュアルです。Gem本体のカスタム指示・設定やGoogleスライドのテンプレートは含みません。

## ファイル

- `index.html`：生徒向け本文と先生の見本スライド
- `examples/teacher-slide-1.png` ～ `teacher-slide-4.png`：提供された「2026材料学習のまとめお手本.pdf」の各ページを、そのまま画像化した見本（1920×1080）
- `style.css`：画面・スマートフォン・印刷用の表示
- `script.js`：印刷ボタン
- `.nojekyll`：GitHub Pagesで静的ファイルをそのまま公開

見本は提供されたPDFから画像化し、サイト内に保存しています。写真の出典・ライセンス表記は元スライド内の記載を保持しています。既存の `LICENSE` を継承しています。

2ページ目の視点は理由を考えるヒントです。すべての視点を網羅したり、「社会性・経済性・環境性」という語句を使ったりする必要はありません。

Gemの質問例は中学1年生が自分の考えや疑問をふだんの言葉で伝える例です。入力欄風の表示は静的な見本で、送信機能はありません。`examples/reference-scissors.jpg` と `reference-door.jpg` は提供PDF内の埋め込み画像をそのまま抽出した参考写真です。椅子の添付表示は自分の写真を貼る場所の例で、実際の椅子の写真ではありません。
